# Spec Delta: request-processing

## MODIFIED Requirements

### Requirement: Populate формы из параметров запроса
Если маппинг объявляет форму, её свойства SHALL быть заполнены параметрами запроса по семантике commons-beanutils, воспроизводимой движком на Spring `ConversionService` (правила конвертации определены в спеке `form-populate`); маппинг без формы SHALL обрабатываться без populate. Multipart-запрос SHALL заполнять форму из разобранных элементов multipart-запроса (текстовые элементы — как параметры, файловые — в свойства соответствующих типов) до вызова экшена; поведение разбора и обработка превышения лимитов SHALL соответствовать спеке `multipart-upload`.

#### Scenario: Параметры заполняют свойства формы
- **WHEN** поступает POST с параметрами, имена которых совпадают со свойствами формы, объявленной в маппинге
- **THEN** к моменту вызова экшена свойства формы содержат значения параметров

#### Scenario: Маппинг без формы
- **WHEN** маппинг не объявляет атрибут `name` с формой
- **THEN** populate не выполняется и экшен вызывается сразу

#### Scenario: Multipart-запрос заполняет файловое свойство
- **WHEN** поступает POST `multipart/form-data` с файловым полем на маппинг с формой, содержащей свойство `FormFile`
- **THEN** к моменту вызова экшена свойство содержит разобранный файл, а текстовые поля формы заполнены из multipart-элементов

# Spec Delta

## Purpose

Публичный англоязычный справочник библиотеки: единое browsable-место, где пользователь может узнать, что такое spring-struts1, как подключить стартер, как мигрировать существующее Struts 1 приложение и что поддерживают тэг-библиотеки и конфигурация стартера.

## ADDED Requirements

### Requirement: Английский язык документации
Все страницы сайта SHALL быть написаны на английском языке. Ни одна страница SHALL не содержать непереведённого текста на русском языке.

#### Scenario: Просмотр любой страницы
- **WHEN** посетитель открывает любую страницу сайта
- **THEN** весь текст страницы — на английском

### Requirement: Набор страниц и навигация
Сайт SHALL содержать шесть страниц: главную (обзор библиотеки), быстрое подключение (getting started), руководство по миграции, справочник тэг-библиотек, справочник конфигурации стартера и обзор модулей. Каждая страница SHALL быть достижима из навигации сайта.

#### Scenario: Навигация по сайту
- **WHEN** посетитель открывает главную страницу
- **THEN** навигация сайта перечисляет все разделы, и каждая ссылка ведёт на существующую страницу

### Requirement: Главная страница
Главная страница SHALL описывать назначение библиотеки (воссоздание Struts 1 поверх современного Spring), её ключевые принципы (сохранение `org.apache.struts.*` API, `struts-config.xml` как источник конфигурации, классические тэг-библиотеки) и таблицу совместимости стека, а SHALL также содержать ссылки на быстрое подключение и руководство по миграции.

#### Scenario: Первое знакомство с библиотекой
- **WHEN** посетитель открывает главную страницу
- **THEN** он видит описание библиотеки, принципы, таблицу совместимости и ссылки на подключение и миграцию

### Requirement: Страница быстрого подключения
Страница getting started SHALL описывать подключение артефактов `org.springstruts` (стартер, тэг-библиотеки, Tiles при необходимости), минимальную настройку `spring.struts1.config`, аннотации `@StrutsAction`/`@StrutsForm` и SHALL ссылаться на руководство по миграции и демо-приложение.

#### Scenario: Подключение библиотеки по инструкции
- **WHEN** посетитель выполняет шаги страницы getting started
- **THEN** он получает работающее приложение на стартере с минимальной конфигурацией

### Requirement: Руководство по миграции на английском
Миграционное руководство SHALL существовать в единственном экземпляре в репозитории (`docs/MIGRATION.md`) и SHALL быть переведено на английский язык с сохранением охвата текущей русскоязычной версии (замена зависимостей, настройка стартера, аннотации, проверка по демо). Ссылка из README SHALL продолжать указывать на этот файл, а страница миграции на сайте SHALL публиковать его содержимое.

#### Scenario: Полнота руководства на сайте
- **WHEN** посетитель открывает страницу миграции на сайте
- **THEN** он видит пошаговое руководство, эквивалентное по охвату текущему русскоязычному `docs/MIGRATION.md`

#### Scenario: Ссылка из README
- **WHEN** читатель README переходит по ссылке на миграционное руководство
- **THEN** ссылка ведёт на существующий файл в репозитории на английском языке

### Requirement: Справочник конфигурации стартера
Справочник конфигурации SHALL описывать свойства `spring.struts1.*` со значениями по умолчанию: `enabled`, `config` (по умолчанию `/WEB-INF/struts-config.xml`), `validating`, `servlet-name`, `mapping.url-pattern`, а также модульные конфигурации `spring.struts1.config.<prefix>`.

#### Scenario: Поиск значения по умолчанию
- **WHEN** посетитель ищет на странице конфигурации значение по умолчанию свойства `spring.struts1.config`
- **THEN** он находит его и описание назначения свойства

### Requirement: Справочник тэг-библиотек
Справочник тэг-библиотек SHALL перечислять библиотеки bean, html, logic, nested и tiles с их классическими URI (`http://struts.apache.org/tags-bean` и аналогичными), указывать, какой артефакт предоставляет каждую библиотеку, и упоминать входящий в артефакт commons-validator.

#### Scenario: Подключение тэг-библиотеки в JSP
- **WHEN** посетитель ищет URI для подключения библиотеки в JSP
- **THEN** он находит классический URI, работающий без изменений

### Requirement: Обзор модулей
Обзор модулей SHALL описывать артефакты группы `org.springstruts` (`spring-struts1-core`, `spring-struts1-taglib`, `spring-struts1-tiles`, `spring-struts1-starter`) и назначение каждого из них.

#### Scenario: Выбор артефактов
- **WHEN** посетитель определяет, какие артефакты подключить
- **THEN** обзор описывает назначение каждого артефакта и его роль
